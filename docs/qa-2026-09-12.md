## 自动回归

新增的组件处理函数测试使用真实组件源码、确定性时钟和轻量 Hook 宿主，不模拟浏览器布局或操作系统输入法。

- 暂停和切后台：第 1 秒上屏，至第 3 秒中断，第 10 秒恢复，第 11 秒再次上屏；有效总时长为 4 秒，两个上屏间隔为 1 秒和 3 秒，中位数为 2 秒。
- 字母及 IME Process 键接入共享按键记录和音效，修饰键、快捷键不计入。
- 中文预编辑文本保留；覆盖 input 在 compositionend 前，以及 compositionend 在最终 input 前两种顺序；完成只保存一次。
- 无物理键事件时的中文直接上屏；取消组合输入不产生虚假成绩。
- 界面契约覆盖两处焦点恢复和无字母按键时的码长提示。

验证命令：`npm run lint`、`npm run typecheck`、`npm test`，以及 `GITHUB_PAGES=true`、`NEXT_PUBLIC_BASE_PATH=/wubi` 下的 `npm run build:pages`。最终状态以本次任务交付消息为准。
